# G-matrices of order 63: symmetry type (kkss), parameters (63; 31, 31, 27, 25; 51).
#
# Not a census: a full enumeration at v = 63 would cover 4^31 pairs of skew
# rows.  These come from nearwill/orbit_solve.c, which asks the two skew rows to
# be constant on the orbits of H = <4> in Z_63^*, reducing that to 2098176
# pairs, and then solves exactly for the two symmetric rows with the mod-4
# linearisation, over all symmetric rows rather than only the invariant ones.
#
# 48 quadruples, forming 1 class under decimation, per-row rotation, per-row
# reversal, per-row negation and permutation of the rows.  Djokovic 2009,
# Table 1, records one known example at these parameters, from E. Spence,
# "Skew-Hadamard matrices of order 2(q+1)", so this reproduces the known entry.
# The other admissible parameter set at v = 63, with row sums 1, 1, 5, 15, is
# left blank in that table and is not reached by any H-invariant skew pair.
#
# Verified by verify/gmat_check.py: autocorrelations sum to zero, row sums
# square to 4v = 252, both enumerated rows skew and both solved rows symmetric,
# and the Goethals-Seidel array is a Hadamard matrix of order 252.
