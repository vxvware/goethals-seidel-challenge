The exhaustive search in arXiv:1802.00556 reports no G-matrices (type kkss) at v=49 for the parameter set (49; 24,24,22,18; 39). The vxvware census finds eight quadruples with exactly that parameter set, one equiv-v1 class, and the rows verify exactly on this board. The same program reproduces the published counts at v=33, 37, 41, 43, and 45.

The four canonical rows, one row of cells per block (A k · B s · C k · D s; k skew, s symmetric), and the Goethals–Seidel array they generate: a Hadamard matrix of order 196. Skew blocks are green and symmetric blocks blue; light is +1 and dark is −1. The drawing is computed from the rows in the browser; the verifier result below is the evidence.
