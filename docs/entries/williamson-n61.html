Lang and Schneider [17] report in their introduction that they implemented the exhaustive algorithm of Holzmann, Kharaghani and Tayfeh-Rezaie [14], extended its results from order 59 to order 61, and found exactly one equivalence class of Williamson matrices of order 61, which is of Turyn type; Bright, Kotsireas and Ganesh [4] cite the enumeration at 61 to that paper. Only the first two pages of [17] were read for this record. The board's own census is a full run of the pinned engine williamson-hkt-v2 on 2026-11-14 (17,359 s on 8 threads), registered as a replay: it returned one class, the Turyn-type quadruple already on the board, so the board's count agrees with the published one. The run is an independent reproduction of a published classification, not a first result.

Original source attribution: Turyn 1972 construction (the class tabulated by Hall and London); classified as the only class at this order by this board's pinned census williamson-hkt-v2
