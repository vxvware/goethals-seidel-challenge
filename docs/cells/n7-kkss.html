The vxvware census recomputes type kkss at every admissible odd order through 45 and agrees with the class counts published by Đoković and Kotsireas [8] at 33, 37, 41, 43, and 45. The imported rows fill the published-not-imported cells with exactly verified representatives.

1 verified class

Each figure shows the four canonical rows and the Goethals–Seidel array they generate, a Hadamard matrix of order 28. Skew blocks are green, symmetric blocks blue and blocks with neither symmetry grey; light is +1 and dark is −1.
